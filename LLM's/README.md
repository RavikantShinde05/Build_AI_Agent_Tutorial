# The Brain of Every existing AI:

Some Most Important concepts that are must to know:

LLM / AI MODEL :
LLM(Large Language Models) is an AI model or known as brain of an Artificial intelligence, we can say a large code use to understand human language,(already pre-trained) understand users given DATA, able to give/take decisions and generate response for human. Initially it's a Chatbot. which can only communicate with humans.

Simply brain of AI :- (LLM)/AI models are trained on large amount of text(DATA) to understand and generate human like response.

PROMPT : 
Prompts are the instruction or Queries you give to AI models. Additionally Data can also be provided with Prompts / Instructions like images, Data sheets, Reports to analyse.

TOKEN : 
In simple words "Tokens" are the small pieces of text an AI model can processes and understand. A token can be a word, part of word, expression, punctuation, or other text. 
The use of AI is bounded initially on the basis of amount of tokens can also be said as credits. As now you can run AI models (Ollama, Kimi, Opencode) locally for free no token limits are applied.

HALLUCINATION : 
An Ai model hallucination happens when a model generates information which sounds convincing but False or fabricated, unsupported or proof with no facts.

To reduce it: Verify facts, test code (Human verification is must), use reliable sources (documents/websites), and retrieve relevant documentation before answering.

AGENTS :
An AI agent is a System which uses AI models (as its brain and itself act as body) to work towards a Goal. It not only communicates but also it can Plan steps, Use tools, Observe results and feedbacks, and Act (adjust its actions). it can be interrupted while doing work.

It requires permissions, it ask for permissions on the criticalness and necessity of execution of step or task. While execute or "run" a command like "bash" or "install" some packages or libraries, depend on users preference how they want to go and complete the task.

SKILLS/(SKILL.md) :
A skill is a reusable set of instructions that directs the AI agents how to perform a particular task, its a file named as SKILL.md which describes the task, steps, rules and what scripts or resources to use. Its like a recipe for any food. Once you write the process, agent will follow that process all the time like its a behavior pattern.
Skill tell how to use the tools capability and MCP is the connector for that tool to the AI application.


MCP : 
MCP (Model Context Protocol) is a standard that allows AI applications to connect to external tools and data Sources. MCPs are used to train AI Models, as it helps AI models to connect to Data sources like (Documents, books, reports, news, Business websites) and external tools like (Slack, GitHub, etc)
MCP are the standard connectors of Agents like our mobile phones charging cable which helps to connect charger, laptop.


## HARNESS :

A HARNESS is a surrounding software system that makes an AI model useful and manageable. Which has prompts, tool connections, memory, permissions, execution logic, error fixing (debugging), error handling and safety checks.

For example a coding harness let an AI model read project files, edit code, run tests, inspects errors, and retry when necessary.


## LOOP ENGINEERING :

Loop Engineering as name itself states that it is practice of designing a repeated cycle in which an AI system work, perform a task, check results and decides what to do next. its a loop or a feedback close loop control system we can say that.


## GEO + AEO :

***Generative Engine Optimization (GEO) & Answer Engine Optimization (AEO):***

Earlier we use to search on the “Google” page asking question to the "Google Search Engine"
which provides us all the related data like websites, documents, videos and images, etc. But here you need to find the one/multiple required suitable/exact solution to your question.

Where as ***"GEO + AEO"*** (After the evolution of AI) provide you the solution to your Query directly from the related sources and facts (A Generated Answer to the Query). An advance level of search and finding solution to the search/research.
